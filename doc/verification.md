# Проверка финальной версии

Окружение: Java 17, Maven 3.9.16, PostgreSQL 17; Docker через Colima на macOS.

| Проверка | Результат |
|---|---|
| `mvn verify` на хосте | 210 тестов, 0 ошибок, 0 пропусков |
| `docker compose build app` | 210 тестов внутри Linux-образа, сборка успешна |
| `docker compose up -d --wait` | PostgreSQL, приложение и nginx healthy |
| PostgreSQL, чистая временная база | Миграции schema и timing-demo применились; ровно 3 статуса примера |
| Интервалы SQL-примера | 09:00 → 13:30 → 15:00; 4 ч 30 мин разработки, 1 ч 30 мин тестирования |
| HTTP напрямую и через nginx | Вход, страницы, CSS, Swagger, отправка формы, выход и отзыв JWT работают |
| Настоящий Tomcat в StatelessHttpTest | GET/POST не создают JSESSIONID; Location не содержит JWT; отсутствующий CSS даёт 404 |
| Chrome | Вход, смена языка, сохранение профиля и данных пользователя, доска и выход проверены |
| Swagger | Документация открыта, новые endpoints тегов и авторизации присутствуют |
| Локальные секреты | `.env` игнорируется; его DB_PASSWORD и JWT_SECRET отсутствуют в отслеживаемых файлах |

Новые сценарии включают положительные и отрицательные пути профиля, валидацию и повторное
добавление тегов, интервалы повторного открытия задач, обработку ошибок загрузки вложений,
локализацию писем, подпись/срок/issuer/audience JWT, отзыв токенов и актуальность ролей.
Одноразовые ссылки регистрации и восстановления проверяются без исходной браузерной сессии.

Настоящий вход через Google/GitHub/GitLab и доставка SMTP не выполнялись: нужны ключи
приложений и почтовый сервер. Тесты проверяют состояние OAuth, редиректы, шаблоны и
внутреннюю обработку ссылок, но не заменяют проверку этих внешних сервисов.

Временная база проверки миграций удалена после успешной проверки. Демонстрационные базы
приложения сохранены. Тестовый PostgreSQL на 5433 больше не нужен: все тесты используют H2.
